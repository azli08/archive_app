# Collectly

Collectly is a personal knowledge management and digital bookmark platform. This repository separates the frontend (`fr`), backend (`bck`), and project documentation (`docs`).

## Repository layout

- `bck/` - Python, FastAPI, PostgreSQL, SQLAlchemy, and Alembic backend.
- `fr/` - React and Vite frontend.
- `docs/` - Project scope, architecture, requirements, and API notes.
- `.gitignore` - Shared ignore rules for local development artifacts and secrets.

See [docs/architecture.md](docs/architecture.md) for the initial module layout and [docs/api.md](docs/api.md) for the API outline.
